缺少配对的 YAML

只加载了 map.pgm

没有同名的 .yaml，编辑器无法知道地图的分辨率和原点，将回退到默认值（0.05 m/px、原点 0,0）。地图在 RViz / Nav2 中会错位。

正确做法 同时选择 map.pgm 与同目录的 map.yaml；也可以把两个文件一起拖进窗口。

帮助与快捷键

打开与导出

打开地图时必须同时选择 .pgm 与同名 .yaml；只选 PGM 会丢失原点和分辨率。导出的文件名固定为 map.pgm 与 map.yaml。

基本操作

滚轮以鼠标位置为中心缩放 空格 + 拖动平移视图（任何工具下均可） 中键拖动平移视图 右键拖动用橡皮擦/清除禁行区 右键多边形：删除上一个顶点 F适应窗口 [ / ]减小 / 增大笔刷 1 / 2 / 3选择障碍 / 空闲 / 未知

工具

H平移 B画笔：涂抹障碍、墙体、空白 E橡皮擦：把像素恢复为空闲 L直线：拖出一条墙线 R矩形：填充或描边 P多边形：逐点单击，双击 / Enter / 点回起点闭合 G油漆桶：按颜色连通区域填充

图层

“地图”层直接修改 PGM 像素；“禁行区”是独立标注层，显示为红色，导出时可生成 Nav2 filter mask，也可“写为障碍/未知”烧录进地图。

关于 PGM 数值

标准 Nav2 地图中：0 = 障碍，254 = 空闲，205 = 未知。编辑器导出时保持 8 位 P5 格式，并按当前分辨率、原点、阈值重新生成 YAML。

关于禁行区与 keepout_filter

导出的掩膜是标准 trinary 地图：禁行处为黑色（occupied），其余为白色（free）。把它交给 Nav2 的 filter_mask_server，并在 costmap 中启用 KeepoutFilter 即可。具体参数名请以你使用的 Nav2 版本为准。

提示

如果只用画笔清理零散噪点，先试“移除小障碍”（阈值 20–60 px）；如果墙体有细小断口，用半径 1–3 的“闭运算”。批量修复同样可以撤销。
